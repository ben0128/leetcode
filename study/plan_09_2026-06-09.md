## 本計畫特定加強重點（常駐 forcing function 由 practice.md 擁有，這裡只記本份重點）

mock #01 剛暴露的 meta 弱項，這份 burndown 拿來反覆鎚：
1. **🔴 事前 test gate（最高優先）**：每題寫第一行 code 前，先**口頭講「哪個 input 最可能打爆我」**。mock 證明這在無人 push 下還沒自發。
2. **「done」的新定義**：= 已試圖打爆它且 `python` 跑過，不是 function 寫完。
3. **複雜度主動精準**：開口就講對（#64 dp 對應、#162 invariant、#127 的 O(M·N²)），不要等被追問。Space 要主動分 aux vs output。
4. **思路-code 對齊**：思路寫什麼、code 就長什麼（return type / 變數作用域）。
