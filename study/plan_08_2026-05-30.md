Plan #7 浮現頭號弱項：#210、#23 共 ~5 次「明確要求自己加會打爆 code 的測試，學生不加 / 加錯 / 要把整行給他才貼」。#210 的環漏判 bug 就是因缺對應測試被「All tests passed!」假 pass 掩蓋。延續 ANALYSIS 既有的 **trace 紀律**弱項。光事後提醒已證實連 5 次無效 → 升級成結構性雙 gate：

**未滿足任一 gate → 自動 ⚠️**，不管 code 對錯。
