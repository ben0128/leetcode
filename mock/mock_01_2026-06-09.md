## 面試流程摘要

### Phase 2 — Clarifying
學生主動問了 3 個關鍵問題：
- 起點/終點有排序嗎？→（答：各組依 start 排序、組內 pairwise disjoint）
- 都是 int？→ 是
- 上下限？→ `0≤start≤end≤10^9`、每組長度 `0~1000`；**學生接住「length 可為 0 → 空陣列」含義**

**缺**：未問「端點剛好接觸（單點交集）算不算」——本題最大隱藏 ambiguity。學生後來用 code（`<=`）與自加 test 處理對，但 clarify 階段沒口頭問出。

### Phase 3 — Approach
- 雙指針 init 兩組 index 0；無交集移動 end 較小邊；有交集記錄。
- **初版 merge 汙染**：「下一個 start = 當前 end+1 可繼續接，不然切斷」——把 9 天前 #56 Merge Intervals 的合併邏輯帶進來。
- 面試官 nudge（把該規則套用到預期輸出的 `[24,24]`/`[25,25]`）→ 學生**一個 nudge 自己翻案**「搞錯了，要拆成兩組」。
- 精修出統一判斷：交集 = `[max(starts), min(ends)]`，`start<=end` 一個條件同時涵蓋「有無交集」。複雜度 O(m+n)。

### Phase 4 — Coding
一次寫對、乾淨。雙指針 + `max/min` + advance-smaller-end。

### Phase 5 — Testing
- 學生先說「done」（**尚未驗證**）。
- 面試官問「怎麼知道對的」→ 答「dry run 跑完三個 ex」（hand-trace 我給的 3 case）。
- 面試官問「你想親手打爆自己會丟哪個我沒放的 input」→ 學生自加：
  `[[1,2],[3,4]],[[2,3],[4,6]] → [[2,2],[3,3],[4,4]]`（連續觸碰端點→單點交集，**品質極高、正中 interval 死穴**）。
- `python` 跑過 → All tests passed。

### Phase 6 — Follow-up（口頭）
1. **k 組共同交集**：學生答「設多指針，O(各長度相加)」→ 骨架對但漏每步成本。面試官 push「每步要先知道 k 個區間的什麼、花多少」→ 學生**自己推出** max/min 每步 O(k) → 總 **O(總長度 × k)**。（面試官補 heap 管 min-end 可降 O(N log k)）
2. **Space 精準度**：學生原寫 O(m+n)；被問「不算 output 呢」→ 正確改口「auxiliary O(1)，含 ans 才 O(m+n)」。

## 學生最終 code

```python
class Solution:
    def intervalIntersection(self, firstList, secondList):
        ans = []
        fLen , sLen = len(firstList), len(secondList)
        if fLen == 0 or sLen == 0:
            return ans
        f, s = 0, 0
        while f < fLen and s < sLen:
            fS, fE = firstList[f]
            sS, sE = secondList[s]
            tmpS, tmpE = max(fS, sS), min(fE, sE)
            if tmpS <= tmpE:
                ans.append([tmpS, tmpE])
            if fE > sE:
                s += 1
            else:
                f += 1
        return ans
```

自加 test：`[[1,2],[3,4]],[[2,3],[4,6]] == [[2,2],[3,3],[4,4]]`
