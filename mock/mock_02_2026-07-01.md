## 面試流程摘要

### Phase 2 — Clarifying
- 主動問 M/N 範圍（→ 1≤m,n≤10）
- 主動問「全 fresh 無 rotten 回什麼」（→ -1，impossible case）——**正中最關鍵的隱藏 case**
- **缺**：沒 clarify「adjacent = 4 向 or 8 向」；「答案為 0」的 case 要面試官提示才想到

### Phase 3 — Approach
- 自己到 multi-source BFS layer-by-layer；counter 記 fresh 數、rot 一顆減一顆、歸零回 minutes、卡住回 -1（乾淨的終止偵測）
- complexity 初寫 `O(m·n + k)`（k=fresh 數）→ 一個 nudge「k ≤ m·n」簡化為 `O(m·n)`；space `O(m·n)` 對
- multi-source 種子（所有 rotten 一起入 queue）理解正確

### Phase 4 — Coding
- 核心 BFS 乾淨：`ways=[1,0,-1,0,1]` + `ways[k],ways[k+1]` 產 4 方向（漂亮 compact trick）、level-by-level、counter 減量
- **🔴 真 bug**：`if not tmp: return 0` — 對 fresh-but-no-rotten（如 `[[1]]`）回 0，應 -1。4 個 given test 都沒蓋到 → **假 pass**

### Phase 5 — Testing（本場最大發現）
- 宣告「done」，跑 4 test「all pass」——但那是假 pass
- 被要求「挑最狠的、我沒放的 input」→ **答不出** fresh-but-no-rotten；即使**學生 clarifying 時親口問過這個 case**（clarify→test 斷層）
- 面試官指 `line 65` 問「這行何時 fire、回 0 永遠對嗎」→ 學生想「直接刪掉」→ 面試官要求 trace `[[1]]` vs `[[0]]`（刪掉會讓 `[[0]]` 回 -1，因 minutes=-1）
- 第一次修：改 `minutes=0` + `minutes+=1` 移到 wave **尾** → 修好 edge case 但**引入 off-by-one**（多算末層 no-op wave → Case 1 得 5）。學生把沒自跑的版本丟給面試官跑 → Case 1 AssertionError
- 第二次修（正確）：`if counter == 0: return 0` 守衛 + 還原 `minutes=-1` 頂端 ++。全 test + 額外 probe（`[[1]]→-1`、`[[2]]→0`、all-rotten→0）皆過
- regression test `[[1,1],[0,1]]→-1` 是被點名後才加

### Phase 6 — Follow-up（口頭，學生因編輯器問題請面試官代答）
- **10^9×10^9 稀疏 grid**：`O(m·n)` 雙重致命（無法配置 10^18 cells + 掃描 10^18 ops）。改用座標集合：`fresh` set of (r,c) + `rotten` queue，BFS 用座標算術取鄰居 + `in fresh` O(1) 判斷 → 時空降到 `O(#oranges)`，與 grid 面積無關

## 學生最終 code

```python
class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        counter = 0
        m, n = len(grid), len(grid[0])
        ways = [1, 0, -1, 0, 1]
        tmp = deque([])
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    counter += 1
                elif grid[i][j] == 2:
                    tmp.append((i, j))
        if counter == 0:
            return 0

        minutes = -1

        while tmp:
            tmpLen = len(tmp)
            minutes += 1
            for _ in range(tmpLen):
                r, c = tmp.popleft()
                for k in range(4):
                    nr, nc = r+ways[k] , c+ways[k+1]
                    if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                        grid[nr][nc] = 2
                        counter -= 1
                        tmp.append((nr, nc))
        return -1 if counter != 0 else minutes
```

## 需改進

- 🔴 **「done」定義**（mock #01 已點、仍未改）：done = 「已試圖打爆自己 + 實際跑過」。兩次把沒自跑的 code 丟給面試官跑。
- **改 bug 別動對的部分**：原 minute 計數本來對，為修 edge 順手改計數 → off-by-one。先定位最小改動點（只需改 line 65）。
- 複雜度主動精準（`+k` 冗餘 → 直接 `O(m·n)`）。
